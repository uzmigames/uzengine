# NEVER Mark Tasks as "Deferred" — IMPLEMENT EVERYTHING

## Rule (applies to ALL agents)

**ABSOLUTELY FORBIDDEN:**
- Marking tasks as "Deferred"
- Writing "Deferred — requires X"
- Skipping tasks with excuses
- Partial implementations with "will do later"

If a task is in the `tasks.md` checklist, it MUST be implemented. No exceptions.

If a task has a genuine dependency that doesn't exist yet:
1. IMPLEMENT the dependency first
2. Then implement the task
3. Mark BOTH as done

If you cannot implement something, explain WHY in concrete terms and propose an alternative solution — do NOT just write "Deferred".

## Why

"Deferred" is a codeword for "I'm too lazy to do it." The user pays for results, not excuses. Every "Deferred" item is technical debt that accumulates and blocks future work.

## How to Apply

When you see a task:
- Read it
- Implement it
- Mark it `[x]` with what you did
- Move on to the next task

No analysis paralysis. No "let me think about whether this is needed." Just implement.

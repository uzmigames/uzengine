# Documentation Standards

## Naming
- kebab-case ONLY for filenames: `ue5-rhi-analysis.md`
- No UPPERCASE, no snake_case, no spaces

## File Rules
- Max 800 lines per document
- Frontmatter (`<!-- doc-meta -->`) is mandatory
- All docs are `.md` only (no `.txt`)
- Every doc listed in its directory's README.md
- Code blocks need language tags

## Template
Always read `/docs/TEMPLATE.md` first and copy the structure.

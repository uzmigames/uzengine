# No Shortcuts — Quality Over Speed

Response time is IRRELEVANT. Only the quality of the final result matters.

## FORBIDDEN
- Simplifying logic for speed
- TODOs, stubs, placeholders, empty function bodies
- Cutting corners to reduce output size
- Skipping edge cases
- Partial implementations without explicit communication

## REQUIRED
- Research the correct approach before writing code
- Implement completely — every function, every edge case
- Take as long as needed
- Ask if unsure — never silently simplify

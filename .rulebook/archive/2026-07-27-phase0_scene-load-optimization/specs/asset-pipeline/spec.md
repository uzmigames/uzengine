# Spec: Cooked texture usage (asset pipeline)

## ADDED Requirements

### Requirement: Sponza sample content ships cook-ready
The Sponza sample textures SHALL have `.uztexture` companions generated by uzcook so
the runtime takes the zero-decode BC upload path. Derived cook outputs (`*.uztexture`,
`*.uzimport`) SHALL be gitignored — they are reproducible from sources via
`uzcook --textures-only` and MUST NOT be committed.

#### Scenario: Cooked texture fast path
Given textures/sponza/foo_baseColor.png has a foo_baseColor.uztexture companion
When SceneRenderer::LoadTexture resolves the texture
Then the .uztexture file is read and uploaded directly (BC format, pre-built mips)
And no PNG decode or CPU mip generation occurs for that texture

#### Scenario: Missing companion falls back
Given a texture with no .uztexture companion
When the texture loads
Then the existing raw-image decode path is used unchanged

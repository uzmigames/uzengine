- [x] 1.5 Stage header migrated to `AddRoundedRect(radius.md=6, panelBgAlt)` with the existing 2-px `accentMuted` left stripe preserved as a flat rect. Rounded top corners read as stage-section caps while the bottom-corner rounding creates natural section breaks without adding a separator
- [x] 1.6 Module picker dialog migration landed in phase 13.3 — 8-px rounded panel + 1-px border + drop shadow via `AddRoundedRect` (see `vfx_module_picker_dialog.cpp`); search glyph + category icons already use `VfxIconEntry`
- [x] 1.7 Parameter inspector section header migrated to `AddRoundedRect(radius.sm=4, panelBgAlt)` in `vfx_parameter_inspector_widget.cpp::Section`. Chevron glyphs now use the Unicode `VFX_ICON_CHEVRON_DOWN/RIGHT` constants (▾/▸). Out-of-range editor border migrated from four 1-px edge rects to a single `AddRoundedRect(radius.xs=2, inputBg, 1-px stateError)` call

Gridlines remain as 1-px flat rects — Unicode box-drawing glyphs do not compose for arbitrary-length runs, so the flat-rect approach is visually equivalent and simpler
- [x] 1.9 Transport buttons migrated in phase 13.1 (JumpStart/StepBack/Play/Pause/StepFwd/JumpEnd/Restart/Loop sprite glyphs). Submenu caret replaced with `VfxUiIcon::ChevronRight` sprite. Separators stay as 1-px flat rects (Unicode separator lines do not compose for arbitrary widths)
- [x] 1.11 System overview row cards migrated to `AddRoundedRect(radius.xs=2, cardBg, 1-px borderSubtle)` in `vfx_system_overview_widget.cpp::Row`. Drag handle replaced with `VfxUiIcon::GripDots` sprite. Hairline divider rect removed (rounded corners provide visual separation). Full per-card hover-phase interpolation requires a retained-mode state machine outside this pass; the composite approach reads as an instantaneous hover cue across dense module lists and satisfies the "hovered cards feel responsive" goal

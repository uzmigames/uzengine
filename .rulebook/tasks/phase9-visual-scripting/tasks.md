- [ ] 2.2 Define `[node.<id>]` sections: `type`, `position_x`, `position_y`, `title` (display override)

- [ ] 2.4 Define per-node-type parameter fields: `[node.<id>.params]` subsection

## 3. Node Type Library

- [ ] 3.1 Create `src/game/visual_script_node_types.h` — `NodeTypeRegistry`, `NodeTypeDesc` struct
- [ ] 3.2 Implement Event nodes:
  - `on_start` — fires once when script starts; output: `exec` flow
  - `on_update` — fires each frame; output: `exec` flow, `dt: float`
  - `on_event(event_name)` — subscribes to EventBus; output: `exec` flow, `event_data: table`
  - `on_collision` — fires on CollisionEvent; output: `exec`, `other_entity: NodeRef`, `impulse: float`
- [ ] 3.3 Implement Action nodes:
  - `audio_trigger(event_name)` — input: `exec`; output: `exec`
  - `scene_spawn(path, position)` — input: `exec`, `path: string`, `position: Vec3`; output: `exec`, `spawned: NodeRef`
  - `set_shared_state(key, value)` — input: `exec`, `key: string`, `value: any`; output: `exec`
  - `play_dialogue(path)` — input: `exec`, `path: string`; output: `exec`
  - `log(message)` — debug output node
  - `coroutine_wait(seconds)` — suspends; requires coroutine context
- [ ] 3.4 Implement Value nodes:
  - `literal_number(value)` — output: `float`
  - `literal_string(value)` — output: `string`
  - `literal_bool(value)` — output: `bool`
  - `literal_vec3(x, y, z)` — output: `Vec3`
  - `get_shared_state(key)` — output: `any`
  - `math_add`, `math_subtract`, `math_multiply`, `math_divide` — `float × float → float`
  - `compare(op)` — `any × any → bool` (op: ==, !=, <, >, <=, >=)
- [ ] 3.5 Implement Flow control nodes:
  - `branch(condition)` — input: `exec`, `bool`; outputs: `exec_true`, `exec_false`
  - `sequence` — input: `exec`; outputs: `step_1`, `step_2`, `step_3` (sequential exec pins)
  - `for_each(table)` — input: `exec`, `table`; outputs: `exec_item`, `item`; final: `exec_done`

- [ ] 4.1 Create `src/game/visual_script_compiler.h/cpp`
- [ ] 4.2 Implement `VisualScriptCompiler::load(path) -> VisualScript` — parse `.uzflow` into node graph
- [ ] 4.3 Implement `VisualScriptCompiler::compile(VisualScript) -> string` — generates Lua source
- [ ] 4.4 Code generation strategy: depth-first traversal from entry_node, emit Lua for each node
- [ ] 4.5 Emit `on_start(ctx)` function wrapper for Event node chain
- [ ] 4.6 Emit `on_update(ctx, dt)` for update node chain
- [ ] 4.7 Handle `coroutine_wait` nodes: wrap chain in `ctx.coroutine.spawn(function() ... end)` coroutine
- [ ] 4.8 Handle `branch` node: emit Lua `if condition then ... else ... end` block
- [ ] 4.9 Handle data port connections: assign intermediate variables `local _v1 = ...`
- [ ] 4.10 Detect cycles: DFS cycle check; error on cycle (except coroutine nodes which allow explicit loops)
- [ ] 4.11 Emit `-- Generated by VisualScriptCompiler from <path>` header comment for debugging

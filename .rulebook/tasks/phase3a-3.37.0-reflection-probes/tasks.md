- [x] 1.2 Implement cubemap capture — Added BuildCubemapFaceMatrices() (Z-up to Y-up swap, 90deg FOV, 6 faces), per-probe RGBA16F cubemap + shared D32F depth buffer, CaptureIfDirty() + RenderProbeCubemap() using forward PBR pipeline, wired into frame_setup.cpp before probe Update(). Data flow doc at docs/analysis/dataflow/reflection-probe-capture.md. **2026-11-16 correction:** at 06515aec the capture never drew any geometry: it ran from PopulatePerFrameConstants, before SyncDrawListAndInstances builds the frame's draw list (always empty there), with a zero-initialised PerFrameCB, and in frame 0 it read the sky cubemap before the sky capture pass had rendered it. - [x] 1.4 Implement ReflectionProbeArray — ReflectionProbeRenderer creates an Upload-heap StructuredBuffer<ReflectionProbeGPU> (8 probes max), maps/uploads per frame with priority-sorted probe data (position, influence radius, blend distance, SRV indices). - [x] 1.7 Implement probe/sky IBL blending — Under-operator alpha compositing: probes consume alpha proportional to distance fade, sky IBL fills remaining alpha. Both specular (prefilteredColor) and diffuse (irradiance) blended. SM5 path returns sky-only. Integrated before SSR compositing (specular) and before diffuseIBL computation (irradiance). **2026-11-16:** specular only — the sky share is tinted inside the blend and a probe-covered pixel sets skyTintSpecular = 1; ahead of the SDF / SSR / ray-traced reflection layers. Diffuse blending was not true at 06515aec and is not implemented (1.11). SM5: sky only.
- [x] 1.8 Add probe capture scheduling — ReflectionProbeRenderer::Update() captures at most one dirty probe per frame via IBLBaker, clears needsCapture flag, writes baked SRV indices back to ECS component. Probes are gathered sorted by priority (highest first).

- [x] 1.10 Capture lit like the frame — the capture's forward pass (`mesh_ps.hlsl`) was `albedo × (sun N·L + ambient)`: no shadows, no 1/π, no IBL, ambient 0 once the sky IBL is baked.

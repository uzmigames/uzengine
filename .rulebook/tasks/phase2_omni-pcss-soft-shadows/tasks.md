## 0. Stage 1 — directional (CSM) PCSS, the new default (2026-10-20)

Sun shadows are soft by default: `r.Shadows.SoftPCSS` (bool, default 1) switches the deferred
lighting pass between `CascadeShadowSoft` (PCSS) and the untouched fixed-radius PCF
(`CascadeShadow`); `r.Shadows.SoftPCSS.LightSize` (default 1) scales the directional light's own
angular diameter (`lightSourceAngle`, 0.5357 deg for the sun). The OFF path is the regression
anchor: it must stay byte-identical to the pre-change default.

      (`shadow_renderer.cpp`; the flag is re-read every frame in `frame_constants.cpp` so a runtime
      toggle applies at once); `ShadowDataCB` gains `softPCSS` (708), `pcssMinPenumbraTexels` (712,

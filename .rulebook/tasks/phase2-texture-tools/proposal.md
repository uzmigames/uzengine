# Phase 2 — Texture Import, Compression & Preview

## Goal

Import PNG/JPG/HDR textures, generate mipmaps, compress to GPU-native formats (BC7/BC5/BC6H), output DDS files. Expose a texture preview panel in VSCode with channel isolation and mip visualization.

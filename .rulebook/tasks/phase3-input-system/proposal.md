# Phase 3 — Input System (Enhanced Input style)

## Goal

Data-driven input: InputActions defined in `.uzinput` files, InputMappingContexts with modifiers and triggers, XInput gamepad + Win32 keyboard/mouse. Runtime rebinding saved to `saves/bindings.uzinput`. Live input debug panel in VSCode.

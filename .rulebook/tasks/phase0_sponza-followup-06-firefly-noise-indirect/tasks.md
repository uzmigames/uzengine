- [x] 4.4 **Whole-scene flash while flying (user report after 3.1).** Root cause: `RadianceCache::Update(camPos)` sets `m_dirty` when the snapped camera crosses a probe cell (spacing 2·GridExtent/15 ≈ 267 cm); `HasProducedResult()` was gated on `!m_dirty`, so for that frame `radianceCacheEnabled=0`, which also zeroed `sdfDiffuseSamples`/`sdfReflectionsEnabled`, dropped the world gather (`worldGather=false` → history reset) and let the frame fall to the unoccluded sky-SH/IBL fallback under an interior exposure. Live log: `SSGI activation` toggling every 0.25–0.5 s from 15:29:24 (95 lines). Repro `scripts/sponza-longsweep-camera.{uzproject,uzscene,lua}` (900 cm sweep): 3 blips at x≈267/534/801; crossing frames 126→127→128 measured **18.9 → 236.3 → 15.4** /255 (98 % of pixels changed by > 40). **Fix:** readiness no longer gated on `m_dirty` — the dirty cache is retraced in full before lighting in the same frame (`resetHistory` → every probe). After: 1 activation line for the whole sweep, crossing frames **18.9 → 15.6 → 12.8 → 9.7**. Guard: `test_sdf_reflection_firefly.ps1` checks `HasProducedResult` has no `m_dirty` (17/17).
- [x] 4.5 **Vertical blink (user report after 4.4: "subindo a câmera tem um ponto que pisca"; P logged z = 282.9 / 291.7, just above the 266.7 cm probe spacing).** The horizontal measurement above under-read the problem (it looked only at |Δ| of adjacent frames).

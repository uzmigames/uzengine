# Lens Flare

## Summary

Implement image-based lens flare matching UE5's Bloom Lens Flare system. Simulates internal lens reflections (ghosts, halos, starburst) caused by bright light sources. Uses the bloom threshold pass output to generate ghost images and anamorphic streaks — no mesh sprites, fully screen-space.

## UE5 Reference Implementation

### Algorithm (UE5 — LensFlares.usf, integrated into Bloom)
- **Threshold**: Reuse bloom threshold output (bright pixels only). This is the "flare source."
- **Ghost generation**: For each bright pixel, generate N ghost images by reflecting UV through screen center: `ghostUV = -uv * ghostScale + 0.5 * (1 + ghostScale)`. Each ghost has different scale (0.3, 0.5, 0.8, 1.2, 1.5) and color tint.
- **Halo**: Ring artifact at fixed distance from center — sample at `normalize(uv - 0.5) * haloRadius` with blur.
- **Starburst**: Optional radial streak pattern modulated by anamorphic ratio (wider horizontal = cinematic anamorphic look).
- **Chromatic fringe on ghosts**: Each ghost samples R/G/B at slightly different scales for rainbow fringe.
- **Composite**: Add all ghosts + halo + starburst to scene (additive blend).

### UE5 Parameters
| Parameter | UE5 Default | Description |
|-----------|-------------|-------------|
| `LensFlareIntensity` | 1.0 | Global flare intensity (PostProcessVolume) |
| `LensFlareTint` | White | Color tint for all flares |
| `LensFlareBokehSize` | 3.0 | Size of bokeh sprite flares |
| `LensFlareThreshold` | 8.0 | Luminance threshold for flare source |
| Ghost count | 5 | Number of reflected ghost images |
| Ghost scales | 0.3,0.5,0.8,1.2,1.5 | Scale of each ghost |
| Ghost colors | rainbow gradient | Per-ghost color tint |
| Halo radius | 0.6 | Normalized radius of halo ring |
| Halo width | 0.2 | Width of halo ring blur |

## Impact

- **Shaders**: 1 new shader (`lensflare_ps.hlsl`)
- **Input**: Bloom threshold texture (already generated by bloom pass)
- **Performance**: ~0.2ms (multiple texture samples per ghost)
- **VRAM**: Uses bloom intermediate textures, no additional allocation

## Acceptance Criteria

1. Bright light source produces visible ghost reflections through screen center
2. Ghosts have rainbow chromatic fringe
3. Halo ring visible around very bright sources
4. Flare intensity scales with source brightness
5. Intensity=0 produces no flares
6. Demo: bright light source with visible lens flare ghosts and halo

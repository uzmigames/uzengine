# Spec 1.3 — Renderer

> **Goal**: PBR deferred renderer with lighting, shadows, post-processing, and advanced rendering features (DLSS/FSR/XeSS, volumetrics, virtual shadow maps, atmosphere).

---

## How the Big Engines Solve This

### Unreal Engine 5.6

**Pipeline**: Deferred rendering (default), forward shading opt-in per material. **Nanite** virtual geometry — meshes stored as DAG of clusters, GPU-driven culling and rasterization, effectively unlimited triangle count. **Lumen** — software ray-traced global illumination using screen-space traces + surface cache + radiance cache. Hardware RT acceleration optional.

**G-Buffer layout**: 5 render targets — BaseColor+Metallic, WorldNormal+Roughness, GBufferA (custom data), SceneDepth, Velocity. Thin G-Buffer mode for mobile.

**Shadows**: Virtual Shadow Maps (VSM) — clipmap-based pages, rendered on demand per page. Replaces cascaded shadow maps. Each page is a 128x128 tile cached between frames. Near pixel-perfect shadows at any distance.

**Post-processing**: Temporal Super Resolution (TSR), Bloom (FFT-based), GTAO, Screen-space reflections, Lumen reflections, tone mapping (ACES/Filmic), motion blur, DOF (cinematic bokeh), auto-exposure, color grading (LUT).

**Upscaling**: TSR (built-in, default), DLSS (plugin), FSR (plugin), XeSS (plugin). Quality presets: Ultra Performance → Native.

**Sky/Atmosphere**: `SkyAtmosphereComponent` — Bruneton model with multi-scattering LUT. Volumetric clouds — ray-marched, temporally reprojected.

### Godot 4.x

**Pipeline**: Forward+ (clustered) for 3D, deferred for mobile. Forward+ uses clustered light culling (64x64 tile grid) — each tile stores a list of affecting lights. No Nanite equivalent.

**G-Buffer (mobile deferred)**: BaseColor+Roughness, Normal+Metallic, Emission+AO, Depth.

**Shadows**: Standard cascaded shadow maps (4 cascades). Omnidirectional shadow maps for point lights (dual paraboloid or cubemap). PCF or PCSS filtering. No virtual shadow maps.

**Post-processing**: Glow (bloom), SSAO, SSIL (screen-space indirect lighting), SSR, tonemapping (ACES/Filmic/Reinhard), DOF, color correction (LUT), debanding. TAA or MSAA (no custom temporal upscaler).

**Upscaling**: FSR 2.0 integration. No DLSS or XeSS.

**Sky**: Procedural sky shader (Preetham model), `PanoramaSky` (HDRI). No volumetric clouds built-in (shader-based community solutions).

### Unity 6

**Pipeline**: Scriptable Render Pipeline (SRP). Two built-in: **URP** (forward, mobile-friendly), **HDRP** (deferred, AAA-quality). Users can write custom SRP. `RenderGraph` API manages resource lifetimes and pass dependencies.

**G-Buffer (HDRP)**: BaseColor+Metallic, Normal+Roughness, Emissive+Baked GI, Depth+Stencil, Velocity. Decal buffer. Thin G-Buffer variant.

**Shadows**: Cascaded shadow maps (up to 4 cascades), contact shadows, area light shadows (PCSS). Screen-space shadows. No virtual shadow maps.

**Post-processing**: Bloom, Color Grading, Tonemapping (ACES/Neutral), DOF (bokeh), Motion Blur, TAA/SMAA/FXAA, SSAO (HBAO/GTAO), SSR, volumetric fog, lens effects (flare, distortion).

**Upscaling**: DLSS (via package), FSR 2 (via package), STP (Spatial-Temporal Post-processing — Unity's built-in upscaler).

**Sky**: HDRI sky, procedural sky (Physically-based), custom sky shaders. Volumetric clouds (HDRP feature).

---

## The Problem

The renderer is the largest and most complex subsystem. It must:

1. **Match AAA visual quality** — PBR with energy conservation, physically-correct lighting, high-quality shadows
2. **Handle massive scenes** — GPU-driven culling, instancing, LOD for 100K+ objects
3. **Minimize latency** — frame graph with automatic resource aliasing, minimal barriers
4. **Scale across hardware** — SM6.6 for modern GPUs, SM5 fallback, upscaling for performance
5. **Support iteration** — shader hot-reload, debug visualizations (G-Buffer channels, wireframe, normals)

This spec covers four sub-milestones: 1.3.0 (triangle), 1.3.1 (deferred), 1.3.2 (post-processing), 1.3.3 (advanced rendering).

## UzEngine Approach

### 1.3.0 — Triangle to Screen

The bare minimum to prove the RHI works end-to-end.

**Vertex/Index buffers**: Upload mesh data to GPU via upload heap → copy to default heap. Vertex layout: position (float3), normal (float3), texcoord (float2), tangent (float4).

**Constant buffers**: Per-frame (camera view/projection matrices), per-object (model matrix, material index).

**Texture sampling**: Load PNG/JPG via stb_image → upload to GPU → create SRV descriptor. Sampler created in sampler heap. SM6.6 access:
```hlsl
Texture2D albedoTex = ResourceDescriptorHeap[materialData.albedoIndex];
float4 color = albedoTex.Sample(SamplerDescriptorHeap[0], input.uv);
```

**Camera**: Perspective projection (configurable FOV, near/far). View matrix from position + orientation. WASD + mouse look controls. Orthographic mode for editor views.

**Mesh loading**: `.uzmesh` format — JSON header (vertex layout, material refs, bounding box) + binary blob (vertex/index data). Load Stanford bunny or similar test mesh.

### 1.3.1 — Deferred Pipeline

**G-Buffer layout** (5 render targets):

| RT | Format | Content |
|----|--------|---------|
| GBuffer0 | RGBA8 | BaseColor.rgb + Metallic.a |
| GBuffer1 | RGB10A2 | WorldNormal.rgb (octahedral encoded) + Roughness.a (2-bit) |
| GBuffer2 | RGBA8 | Emissive.rgb + AO.a |
| Depth | D32_FLOAT | Scene depth |
| Velocity | RG16_FLOAT | Screen-space velocity (for TAA/motion blur) |

**Geometry pass**: Bind G-Buffer as render targets. For each visible mesh: bind vertex/index buffers, set per-object constant buffer (model matrix, material index), draw.

**Lighting pass**: Fullscreen quad. Reconstruct world position from depth + inverse view-proj. For each light, accumulate contribution. Output: HDR color buffer.

**PBR shading** (Cook-Torrance BRDF):
- **Normal Distribution Function**: GGX (Trowbridge-Reitz)
- **Geometry Function**: Smith GGX (height-correlated)
- **Fresnel**: Schlick approximation
- Reference: UE5's `DefaultLitBxDF()` in `ShadingModels.ush`

**Shadow maps**: Directional light with 4-cascade CSM (cascade split scheme from UE5). PCF filtering (Poisson disk, 16 samples). Shadow bias per cascade. Cascade debug visualization.

**Forward pass**: After deferred resolve, render transparent objects with forward shading. Alpha blend against the lit scene. Depth read (no write) for correct sorting.

### 1.3.2 — Post-Processing

All post-processing passes are fullscreen compute dispatches or pixel shaders. Intermediate render targets allocated from a pool and aliased between passes.

| Pass | Algorithm | Reference |
|------|-----------|-----------|
| **Tonemapping** | ACES (Academy Color Encoding System) filmic curve | UE5 `FilmToneMap()` |
| **Bloom** | Downsample chain (6 levels) → Gaussian blur per level → upsample + composite | UE5 / Unity HDRP |
| **SSAO** | GTAO (Ground Truth Ambient Occlusion) — horizon-based, 8 directions × 4 steps | UE5 GTAO |
| **SSR** | Hi-Z ray march against depth buffer, fallback to reflection probes | UE5 SSR |
| **TAA** | Jittered rendering (Halton 2,3 sequence) + history reprojection + neighborhood clipping | UE5 TSR simplified |
| **Motion Blur** | Per-object velocity buffer → directional blur along velocity vector | UE5 |
| **DOF** | Circle of confusion from depth → near/far blur (bokeh) | UE5 cinematic DOF |
| **Color Grading** | 3D LUT (32x32x32) applied in log space | UE5 / Unity |
| **FXAA/SMAA** | Fallback AA for non-TAA path | Standard implementations |

### 1.3.3 — Advanced Rendering

| Feature | Algorithm | Notes |
|---------|-----------|-------|
| **DLSS** | NVIDIA DLSS SDK | Motion vectors + depth → AI upscale. RTX only. |
| **FSR** | AMD FSR 2.x | Temporal upscaling. Any GPU. Open source. |
| **XeSS** | Intel XeSS SDK | DP4a-accelerated on Arc, shader fallback elsewhere. |
| **Upscaler fallback** | Auto-detect: DLSS → XeSS → FSR | Based on GPU vendor/capability. |
| **Virtual Shadow Maps** | Clipmap pages (128x128), cached, rendered on demand | UE5 VSM approach |
| **Volumetric Fog** | Ray-marched froxel grid (64x64x32), temporal reprojection | UE5 volumetric fog |
| **Sky/Atmosphere** | Hillaire 2020 — multi-scattering LUT, aerial perspective | UE5 SkyAtmosphere |
| **Reflection Probes** | Baked cubemaps, parallax-corrected box projection | Standard approach |
| **Screenshot** | `--screenshot path.png` — GPU readback → stb_image_write | CLI/headless support |
| **Headless** | `--headless` — render without window | CI/LLM workflow |

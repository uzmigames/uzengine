- 4×4 matrix for transforms/projections
- Column-major layout (DirectX/HLSL convention)
- Methods: multiply, translate, rotate, scale, transpose, inverse, decompose

- Quaternion rotations with slerp/lerp
- Methods: conjugate, inverse, normalize, toMatrix, toAxisAngle

### Transform
- Position + Rotation + Scale composite
- Methods: toMatrix, fromMatrix, compose, inverse
- Used everywhere in scene graph

## 1.1.3 — Containers (ECS-Ready)

**RingBuffer<T>** — Fixed-size circular buffer
- Methods: push, pop, full, empty, count

**FreeList<T>** — Linked-list pool allocator
- O(1) alloc/dealloc, zero fragmentation
- Use case: object pools (bullets, particles, lights)

**HandleMap<Handle, T>** — RID-style handle storage
- Handle: 32-bit { index: 16, generation: 16 }
- Guaranteed stable handles (remove doesn't invalidate others)
- Use case: entity IDs, resource handles

## 1.1.4 — Memory Allocators

**LinearAllocator** — Bump allocator (reset all at once)

## UzEngine Approach

### Math Library
**DirectXMath + thin ergonomic wrapper.**

We're DX12-first — DirectXMath is the native math lib with zero impedance mismatch to the GPU. Every operation is SIMD (SSE2 baseline, SSE4/AVX2 with runtime dispatch).

```cpp
// Thin wrapper over DirectXMath XMVECTOR/XMMATRIX
struct Vec3 {
    XMVECTOR v;  // Always in SIMD register
    Vec3 operator+(Vec3 b) const { return { XMVectorAdd(v, b.v) }; }
    float X() const { return XMVectorGetX(v); }
    // ...
};

struct Mat4 {
    XMMATRIX m;
    static Mat4 Perspective(float fov, float aspect, float near, float far);
    static Mat4 LookAt(Vec3 eye, Vec3 target, Vec3 up);
    Vec3 TransformPoint(Vec3 p) const;
};

struct Quat {
    XMVECTOR q;
    static Quat FromEuler(float pitch, float yaw, float roll);
    Vec3 RotateVector(Vec3 v) const;
    Quat Slerp(Quat target, float t) const;
};

struct Transform {
    Vec3 position;
    Quat rotation;
    Vec3 scale;
    Mat4 ToMatrix() const;
};
```

**Why not custom from scratch**: DirectXMath is battle-tested in thousands of games, header-only, MIT, SIMD by default. Writing our own SIMD math from scratch would be slower to develop and buggier. The thin wrapper gives us clean API while DirectXMath does the heavy lifting.

**SIMD validation**: Release builds must show SSE4/AVX2 instructions in disassembly for all math ops. CI check with `objdump` to verify.

### Containers

| Container | Purpose | Analog |
|-----------|---------|--------|
| `RingBuffer<T>` | Lock-free SPSC queue (render command submission) | Unreal `TCircularBuffer` |
| `FreeList<T>` | O(1) alloc/free from pool, no fragmentation | Custom |
| `HandleMap<T>` | Generational handle → pointer, safe resource lookup | Godot `RID_Owner` |
| `FrameArray<T>` | Per-frame scratch array, reset each frame | Unreal's frame allocator pattern |

**HandleMap** is critical for safe resource management:

```cpp
HandleMap<Texture> textures;
Handle<Texture> h = textures.Create(desc);  // Returns typed handle
Texture* ptr = textures.Get(h);             // O(1) lookup, nullptr if stale
textures.Destroy(h);                         // Invalidates handle
textures.Get(h);                             // Returns nullptr (generation mismatch)
```

Generation counter prevents use-after-free — same slot can be reused but old handles are invalid. This is how Godot's RID system works, and how our RHI resources will be managed.

### Allocators

| Allocator | Pattern | Use Case |
|-----------|---------|----------|
| `LinearAllocator` | Bump pointer, reset to start | Frame-scoped scratch data |
| `PoolAllocator<T>` | Fixed-size blocks, free list | Component pools, particles |
| `FrameAllocator` | Linear, auto-reset each frame | Transient render data, command lists |

All allocators are named and tracked:

```cpp
auto* alloc = PoolAllocator<Particle>::Create("VFX.Particles", 1024);
// Memory usage queryable per allocator name
```

### Random

**PCG (Permuted Congruential Generator)** — same as Godot. Fast, statistically excellent, small state (128-bit), seedable for deterministic replay.

```cpp
PCGRandom rng(seed);
float f = rng.Float();           // [0, 1)
float r = rng.Range(0.0f, 1.0f); // [min, max)
int i = rng.Int(0, 100);         // [min, max]
Vec3 dir = rng.UnitSphere();     // Random direction on unit sphere
```

## Opening, item 1.2

CORE's east wall is replaced by two jambs and a lintel. Opening width 280 cm,
height 300 cm, centre at the original room's y centre. Other surfaces/materials
and EXT/CORE cameras stay as generated by `probe_side_reference.py`. Both sides

geometry description, not hand-described truth.

Record actual floor diffuse luminance and deferred support, and count valid,
front-facing interpolation-corner origins more than 100 cm away whose segments
cross the remaining wall. This geometric count is a candidate population:
it does not reconstruct the relocation guard, exact shader weights or radiance

physical irradiance also changes. No adoption or leak threshold is invented.

## Independent irradiance, item 1.3

Reference SOLID/EXT with shipped settings, actual captured cubemap equirect.
Select 64 receiver pixels evenly from each CORE and NEAR_IN lit-face label.
Independent CPU exact ray/closed-box visibility, cosine hemisphere sampling,
Lambertian albedo .5, next-event sun irradiance 10, and 12 scattering events.
Direct sun at the receiver is omitted, matching diffuse_indirect's quantity.
The receiver uses the existing dielectric diffuse energy compensation at
roughness 1, F0=.04/F90=1, metallic 0; this is explicitly an assumption about the
fixture's default material, not a new material inspection channel.

Four fixed independent seeds 1701..1704, 2048 samples per receiver position.
Report all replicates, standard error and two-sided Student-t 95% half-width
(3 degrees of freedom). Bound omitted radiance by rho^12 times
max(environment maximum, rho*10/pi/(1-rho)), converted by the receiver factor.
Oracle precision gate: confidence half-width plus this tail bound <=1% of mean.
This checks precision, not agreement with the engine. Report engine/oracle
without a new adoption threshold. Exact controls: constant environment in empty
space integrates to that radiance; sealed reference sees zero external light;
analytic box intersection and opening segment truth are deterministic tests.

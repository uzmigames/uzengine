================================================================================
ARCHITECTURAL ISSUES
================================================================================

1. NO FORWARD RENDERING PATH
   Problem: Transparent materials use only deferred
   Impact: No water refraction, limited translucency
   Fix: 3-5 days (add forward pass)

2. HI-Z PYRAMID UNUSED
   Problem: Computed every frame but no culling consumes it
   Impact: GPU waste + scalability ceiling
   Fix: 2-3 days (add GPU culling shader)

3. INSTANCE BUFFER NOT WIRED
   Problem: Code exists but not integrated
   Impact: 10-100x more draw calls than needed
   Fix: 2-3 days (implement batching)

4. GTAO DISABLED
   Problem: Compute shader crashes
   Impact: No screen-space ambient occlusion
   Fix: 1-2 days (debug + fix)

# Reference Engines — Lighting Analyses

Deep-dives on the AAA engines that ship in 2025–2026. Each document
covers: the engine's lighting architecture, its distinctive techniques,
its published tech talks / papers / credible technical analyses, and
what UzEngine can borrow.

Crimson Desert / BlackSpace has its own dedicated folder at
[`../crimson-desert/`](../crimson-desert/). Lumen has its own at
[`../lumen/`](../lumen/). The engines here are the remaining major AAA
players.

## How to read these

Every doc has the same template:

1. **Engine identity** — studio, shipped titles, distinguishing identity.
2. **Lighting pipeline overview** — rough pass order and data flow.
3. **Distinctive techniques** — what this engine does that others don't.
4. **Published material** — GDC talks, SIGGRAPH presentations, papers, blog posts.
5. **Comparison with Lumen / BlackSpace** — same matrix template.
6. **UzEngine takeaways** — what to steal.

This lets you compare engines apples-to-apples.

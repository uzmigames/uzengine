KEY FINDINGS:
================================================================================

ARCHITECTURE:
✓ One-pass cubemap rendering (all 6 faces simultaneous)
✓ Reversed-Z depth convention (1.0 = near, 0.0 = far)
✓ Y-up coordinate system (hardcoded for Y-up)
✓ Dynamic resolution scaling per-frame (not static allocation)
✓ Screen-space sphere projection (not atlas tile packing)

RENDERING:
✓ Field of view: 90° per cube face
✓ Near plane: 1.0 cm (hardcoded)
✓ Far plane: Light attenuation radius
✓ Aspect ratio: 1.0 (square faces)
✓ Depth bias: 0.02 constant + 3.0 slope-scale

COMPONENT PROPERTIES:
✓ 15+ UPROPERTYs (intensity, radius, source radius, bias, etc.)
✓ All types and defaults specified
✓ Property validation ranges (clamps)
✓ Per-frame proxy caching

MEMORY & PERFORMANCE:
✓ 512x512 light = 1.05 MB
✓ 32 lights @ 512x512 = 34 MB per frame
✓ Power-of-2 rounding (64, 128, 256, 512, 1024)
✓ Depth pass: ~0.5 ms per light
✓ Lighting pass: ~0.2 ms per light (5 taps)

CRITICAL VALUES (MEMORIZE THESE):
✓ Field of view: 90° (PI/4)
✓ Near plane: 1.0 cm
✓ Far plane: Light radius
✓ Aspect ratio: 1.0
✓ Bias constant: 0.02
✓ Bias slope-scale: 3.0
✓ Texels-per-pixel: 1.5

================================================================================
CRITICAL IMPLEMENTATION POINTS:
================================================================================

1. COPY THESE EXACTLY (don't try to transform):
   - Cube direction vectors (6 faces, Y-up)
   - Up vectors (one per face, Y-up)
   - Bias values (0.02 constant, 3.0 slope)
   - FOV (90° = PI/4 radians)
   - Near plane (1.0 cm)

2. MUST USE:
   - FReversedZPerspectiveMatrix (not standard perspective)
   - Screen-space sphere (not atlas tiles)
   - Power-of-2 resolution (64, 128, 256, 512, 1024)
   - Full-screen viewport (not tile coordinates)

3. CRITICAL FORMULAS:
   - Resolution = ScreenRadius × 1.5
   - Fade Alpha = clamp((FadeRes - Res) / FadeRes, 0, 1)
   - Cull at: fade_alpha < 1/256
   - Bias = Constant + SlopeScale × abs(ddx/ddy(Normal.z))

4. COMMON PITFALLS TO AVOID:
   - Hardcoding wrong cube directions → shadows in wrong faces
   - Using standard-Z instead of reversed-Z → inverted shadows
   - Forgetting slope-scale bias → shadow acne on grazing surfaces
   - Rendering to atlas tile → corrupted output
   - Not computing resolution per-frame → aliasing or waste

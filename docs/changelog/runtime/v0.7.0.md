- **Shadow** (6): PCFPenumbraRadius, PCSSMin/Max, ESMExponent, ContactSteps/Thickness

- **SVGF** (4): SigmaDepth/Normal/Luminance, MomentsSigmaNormal
- **Bloom/Exposure** (6): Knee, KeyValue, SpeedUp/Down, Low/HighPercent

- **Cloud FBM** (7): NoiseXY/ZScale, ShapeOctaves, FBMDecay/Lacunarity, DetailErosion, DensityScale
- **SSR** (2): MaxRoughness, Intensity
- **PerFrameCB** extended with 14 CVar fields using padding slots (768 bytes maintained)
- **HLSL cbuffer alignment fix**: DXC aligns float4 arrays to 16-byte boundaries — verified all offsets via `dxc -Fc` reflection

### Stephen Hill ACES Fit
- **ACESHillFit()** in `color.hlsli`: fitted RRT+ODT matrices with better hue preservation than Narkowicz
- **Tonemap operator CVar**: `r.TonemapOperator` (0=None, 1=Hill, 2=Narkowicz, 3=Reinhard, 4=Hable)
- **Specular occlusion**: `ComputeSpecularOcclusion()` extracted as named function in `ibl.hlsli`
- C++ mirrors: `ACESHillFit()`, `ACESNarkowicz()`, `ComputeSpecularOcclusion()` in `brdf_math.h`

### DLSS Integration
- **NVIDIA DLSS temporal upscaler** via dynamic NGX loading (LoadLibrary/GetProcAddress)
- **DlssUpscaler** class implementing ITemporalUpscaler (PIMPL, 5 quality presets)
- Graceful fallback: non-NVIDIA GPUs get TSR/FSR automatically
- CLI: `--upscaler dlss`, `--dlss-quality quality`
- CVars: `r.DLSS.Quality`, `r.DLSS.Sharpness`
- No MSVC CRT dependency (avoids Zig/mingw incompatibility)

### Anisotropic GGX BRDF
- **D_GGXAniso()**: anisotropic Trowbridge-Reitz NDF (Burley 2012)
- **V_SmithGGXCorrelated_Aniso()**: anisotropic visibility (Heitz 2014)
- **RemapAnisotropy()**: roughness + anisotropy → per-axis alpha (glTF KHR_materials_anisotropy)
- C++ mirrors in `brdf_math.h`

### Mesh Normal Smoothing + MikkTSpace Tangents
- **ComputeSmoothNormals()**: area × corner angle weighted averaging with 60° hard edge threshold
- **MikkTSpace tangent generation**: industry-standard tangents matching UE5/Unity/Blender
- FBX importer: always recompute smooth normals (replaces flat normals)
- glTF importer: preserve imported normals, MikkTSpace for missing tangents
- Spatial hash adjacency for O(n) vertex grouping

### Bug Fixes
- **Tonemap debug early-return removed**: bindless path was returning raw HDR without any tonemapping
- **CloudCB alignment**: padded to 512 bytes (DX12 CBV 256-byte alignment requirement)
- **HLSL cbuffer float4 array alignment**: DXC inserts implicit padding before float4 arrays
- **CVarRegistry::Get() deprecated**: replaced with proper UZ_CVAR declarations in SSR code
- **Tonemap passthrough default**: scene calibrated without tonemapping, ACES opt-in via CVar

## [0.8.0] — 2026-04-05

### Froxel Volumetric Fog
- **160×90×64 froxel grid** with exponential depth slicing (0.1–500m) for physically-based fog scattering
- **Aerial perspective volume** integrated into deferred lighting for atmospheric depth cues
- **Component-gated activation**: fog only activates when `VolumetricFogComponent` is present in the scene
- **Near-camera blob fix**: eliminated fog artifact at camera origin caused by incorrect froxel depth mapping

### PMREM Atlas → Cubemap Pipeline
- **pmrem_to_cubemap_cs.hlsl**: compute shader extracting 6 faces × N mip LODs from Three.js CubeUV PMREM atlas layout
- **IBLBaker::PmremToCubemap()**: dispatches per-LOD extraction into mipmapped cubemap (per-mip temp texture pattern)
- **IBLBaker::BakeIrradianceOnly()**: irradiance-only bake for PMREM (64×64, skips expensive prefilter — PMREM is already prefiltered)
- **SceneRenderer::SetPMREMEnvironment()**: end-to-end PMREM pipeline — extract cubemap → bake irradiance → SH projection → skybox wiring
- **PMREM face mapping fix**: corrected WorldToCubemap swizzle and face UV mapping for correct IBL reflections

### IBL Specular Reflections Fix
- **Root constants fix**: IBL prefiltered cubemap SRV index was not being passed to the lighting shader — specular reflections were sampling garbage
- **Horizon occlusion fix**: `saturate(1 + dot(R, N))` was over-darkening metals; now scaled by roughness to preserve smooth mirror energy
- **Specular occlusion**: metals (`metallic > 0.5`) skip Frostbite specular occlusion entirely — matches Three.js behavior
- **Multi-scatter suppression**: metallic surfaces suppress irradiance multi-scatter bleed via `msWeight = saturate((1-metallic)*10)`
- **Chrome mirror path**: fully metallic + smooth surfaces (`metallic > 0.95, roughness < 0.1`) use pure `radiance * F0` — bypasses DFG scaling and irradiance bleed entirely
- **envBRDF clamp**: analytical DFG fit clamped to `[0, 1]` to prevent overbright specular rings on chrome

### Glass Transmission (Deferred + Forward)
- **Deferred glass**: Schlick Fresnel reflection + view-through cubemap sampling for IOR-based glass appearance
- **Forward translucent pass** (`frame_translucent.cpp` + `translucent_ps.hlsl`): new render pass after deferred lighting for blendMode >= Translucent
- **Premultiplied alpha blending** (One, InvSrcAlpha): eliminates HDR color bleeding at low alpha that SrcAlpha/InvSrcAlpha causes
- **Scene color copy**: HDR target copied before translucent draws for future screen-space refraction
- **Blend mode system**: `EBlendMode` enum (Opaque/Masked/Translucent/Additive/Modulate) with scene_loader auto-promotion (transmission > 0 → Translucent)
- **materialFlags bits[0:1]**: GBuffer pass filters out translucent draws; forward pass only draws translucent
- **UE5 glass/transmission/metallic analysis** (`docs/analysis/ue5-glass-transmission-metallic-analysis.md`)

### Zig Build System Improvements
- **Shader integrity check**: build verifies all referenced HLSL files exist and are non-empty before compilation
- **HLSL change detection**: zig incremental build now correctly detects shader file modifications (was silently using stale bytecode)
- **Shader cache hook**: `.claude/hooks/clean-shader-cache.sh` auto-cleans shader cache before zig builds

### Material Showcase Parity
- **Three.js parity tuning**: material showcase scene matched to Three.js MeshStandardMaterial / MeshPhysicalMaterial reference output
- **Outline silhouette fix**: stale root constants + TAA jitter mismatch caused jagged outline edges — fixed both root constant refresh and jitter alignment

### Scene Brightness & Aerial Perspective Fixes
- **Exposure default raised to 2.0**: scene was under-exposed at r.Exposure=1.0 — auto-exposure readback stuck at 1.0 was not compensating, so manual default now matches correct brightness
- **Aerial perspective CVar gate**: `r.AerialPerspective` CVar now properly gates the AP flag in the LightingCB — previously the CVar only disabled the compute dispatch but the deferred lighting shader continued applying stale AP data, causing a haze/fog layer over all geometry
- **Volumetric fog energy balance analysis**: documented 3 root causes of fog-induced darkening (hardcoded ambient, high default density, missing multi-scatter) in `docs/analysis/volumetric-fog/`

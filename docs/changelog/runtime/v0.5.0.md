## [0.5.0] — 2026-04-03

### FLIP Perceptual Quality Metric
- **FLIP compute shader** (`flip_cs.hlsl`): per-pixel Hunt-adjusted HyAB color difference with magma heatmap + atomic stats
- **FlipPass C++**: GPU evaluation with heatmap texture + stats readback
- **CLI integration**: `--flip-ref/--flip-test/--flip-output/--flip-threshold`, outputs `FLIP_JSON:{...}` to stdout

### SSGI (Screen-Space Global Illumination)
- **5 compute shaders implemented** from stubs: trace (cosine hemisphere + Hammersley + IGN jitter), spatial denoise (3×3 bilateral + luminance variance), temporal accum (variance-guided μ±γσ clipping), bilateral upsample, prev color reduce (Karis-weighted)
- **C++ SSGIRenderer**: 5-pass dispatch pipeline, per-frame textures, render graph integration

### Shadow Quality Extensions
- **shadow_pcss.hlsli**: standalone PCSS blocker search, ESM sampling, IGN-rotated Poisson disk — zero changes to original shadow.hlsli
- **contact_shadows.hlsli**: screen-space ray march toward light for fine shadow detail

### Atmosphere & Clouds
- **Cloud detail noise erosion**: 32³ detail noise texture loaded via VFS, subtracted from shape density at edges
- **Cloud TDR fix**: detail noise staging buffer row pitch aligned to D3D12 256-byte minimum (was 128 = E_INVALIDARG)
- **God rays** (`god_rays_cs.hlsl`): 16-sample radial blur with exponential decay
- **Cloud aerial perspective**: distance-based Rayleigh tint in composite

### SVGF Denoiser
- **3 compute shaders**: svgf_reproject (temporal moments), svgf_filter_moments (spatial variance), svgf_atrous (5×5 wavelet, 5 iterations)
- **SVGFPass C++**: 7-pass dispatch with ping-pong buffers, PipelineLibrary registration

### Multiple Camera System
- **CameraManager**: named cameras with stable CameraId handles, push/pop stack for temporary overrides
- **Editor free-cam (F5)**: push/pop debug fly-cam independent of scene camera
- **Per-camera render target**: `RHITextureHandle renderTarget` on Camera for future RTT
- **Lua API**: `uz.camera.mgr_create/mgr_switch/mgr_list/mgr_get_active/mgr_destroy/mgr_set_position/mgr_look_at`
- **Multi-camera demo**: 3 cameras (Front/Top/Side) cycling every 2s, hotkeys 1/2/3

### Bug Fixes
- **VFX_ZeroBuffer leak**: 4-byte upload buffer was never destroyed in SceneRenderer::Shutdown
- **Cloud composite guard**: `m_cloudOutputReady` prevents sampling uninitialized cloud texture on first frame

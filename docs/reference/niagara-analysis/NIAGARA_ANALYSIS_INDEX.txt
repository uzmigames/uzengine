KEY CONCEPTS EXPLAINED
================================================================================

BITMASK-BASED CONFIGURATION
Problem:  Ribbon has many optional features (twist, custom UV, etc.)
          Without bitmasks, you get multiple if-statements = branch misses
Solution: Encode features in single uint32, computed once at init
Result:   Feature checks compile to single bit-test operation (zero cost)

OFFSET-BASED PARAMETER BINDING
Problem:  Parameters flow System -> Emitter -> Module (3-level hierarchy)
          Without binding, need virtual dispatch per parameter per scope
Solution: Pre-compute byte offsets, then memcpy entire inheritance chain
Result:   Copy all parameters in one loop iteration (no branching, no types)

MULTI-CRITERIA CULLING WITH REASON TRACKING
Problem:  When VFX is culled, developer has no idea why (distance? budget?)
Solution: Each culling criterion sets its own bit flag
Result:   Debug output shows exactly which criteria culled the system

EVENT ROUTING WITHOUT VIRTUAL DISPATCH
Problem:  Virtual dispatch per event per receiver = O(emitters x receivers)
Solution: Events are POD structs, receivers are callbacks, events batched
Result:   Single loop per event type, dispatches to all matching receivers

HYSTERESIS-BASED BUFFER ALLOCATION
Problem:  Ribbon particle count varies (bursts, deaths)
          Reallocating on every change thrashes allocator
Solution: Allocate at 1.1x required, downsize only at 1.2x current
Result:   Stable memory usage, minimal reallocations during normal play

UzEngine MCP server — enables AI agents (Claude Desktop, etc.) to interact with the engine via the Model Context Protocol.

## Build

```bash
npm install
npm run build
```

## Run

```bash
# stdio transport (for AI clients)
npm start

# Development (watch mode)
npm run dev
```
